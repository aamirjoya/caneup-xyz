<div class="fp-cards">

<div class="fp-card"><div class="fp-card-icon">💳</div><h4>DBT</h4><p>सीधे बैंक खाते में — कोई बिचौलिया नहीं</p></div>

</div>

<div class="fp-alert"><strong>देरी होने पर:</strong> 14 दिन बाद भी पैसा न आए तो मिल पर <strong>15% सालाना ब्याज</strong> लगता है। यह आपका कानूनी हक है — शिकायत करने से न डरें।</div>

<div class="fp-section">
<h2>भुगतान कैसे चेक करें — 3 तरीके</h2>
<div class="fp-steps">
<div class="fp-step"><div class="fp-step-num">1</div><div class="fp-step-body"><h4>CaneUp — Grower Code से</h4><p>ऊपर Grower Code डालें → UP Payment Portal पर redirect होगा → भुगतान की तारीख और राशि दिखेगी।</p></div></div>
<div class="fp-step"><div class="fp-step-num">2</div><div class="fp-step-body"><h4>eGanna App से</h4><p>eGanna App → लॉगिन करें → "भुगतान स्थिति" → सीजन चुनें → पूरा भुगतान विवरण दिखेगा।</p></div></div>
<div class="fp-step"><div class="fp-step-num">3</div><div class="fp-step-body"><h4>sugarcane.up.gov.in से</h4><p>UP गन्ना विभाग की वेबसाइट → "किसान भुगतान" → Grower Code डालें → स्टेटस देखें।</p></div></div>
