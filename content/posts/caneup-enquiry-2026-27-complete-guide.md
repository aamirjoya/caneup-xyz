CaneUp (caneup.in) उत्तर प्रदेश गन्ना विकास परिषद का **official portal** है। इस एक portal से आप अपनी **गन्ना पर्ची**, **भुगतान स्टेटस**, **सर्वे डेटा**, **सोसायटी कोड** — सब कुछ चेक कर सकते हैं।

## CaneUp Portal पर क्या-क्या चेक कर सकते हैं?

| सुविधा | कहाँ मिलेगी |
|--------|-------------|
| 🎫 गन्ना पर्ची कैलेंडर | Enquiry → Supply Ticket |
| 💰 भुगतान स्टेटस | Enquiry → Payment Status |
| 📋 सर्वे डेटा | Enquiry → Survey Data |
| 🏭 मिल-वार भुगतान | Enquiry → Mill Payment |
| 👤 किसान विवरण | Enquiry → Grower Details |
| 📊 Recovery Rate | Enquiry → Recovery |

## Step-by-Step: CaneUp Enquiry कैसे करें

### Step 1: Portal खोलें
- Browser में जाएं: **[caneup.in](https://caneup.in)**
- या Google में search करें: **"caneup enquiry"**

### Step 2: Enquiry Section चुनें
- Homepage पर **"Enquiry"** button पर click करें
- या direct link: `caneup.in/enquiry`

### Step 3: जानकारी भरें

| Field | क्या भरें |
|-------|----------|
| Crushing Year | **2026-27** (latest season) |
| Mill | अपनी **चीनी मिल** का नाम चुनें |
| Village | अपना **गाँव** चुनें |
| Society | अपनी **सोसायटी** चुनें |
| Grower Code | अपना **ग्रोवर कोड** डालें |

### Step 4: Submit करें
- **"View"** या **"Submit"** button दबाएं
- आपकी पूरी जानकारी screen पर आ जाएगी

## गन्ना पर्ची कैलेंडर कैसे देखें

गन्ना पर्ची कैलेंडर से पता चलता है कि **आपकी गन्ना कटाई की बारी कब** आएगी।

### तरीका 1: CaneUp Portal
1. [caneup.in](https://caneup.in) → **Enquiry**
2. **"Parchi Calendar"** या **"Supply Ticket"** select करें
3. अपना **Crushing Year**, **Mill**, **Village**, **Society** भरें
4. **Grower Code** डालें → Submit
5. आपकी **scheduled date** दिख जाएगी

### तरीका 2: eGanna App
1. **eGanna App** खोलें (Google Play से download)
2. Login करें → **"पर्ची कैलेंडर"** पर tap करें
3. अपना data verify करें
4. **तारीख और time slot** दिख जाएगा

### तरीका 3: SMS से
- अपने registered mobile से **SMS** भेजें
- Format: `PARCHI <Grower Code>` → **1800-121-3203** पर

## भुगतान स्टेटस कैसे चेक करें

### CaneUp Portal से:
1. [caneup.in](https://caneup.in) → **Enquiry** → **Payment Status**
2. **Crushing Year 2025-26** select करें
3. अपना **Grower Code** डालें
4. **कितना भुगतान हुआ**, **कब हुआ**, **कितना बाकी** — सब दिखेगा

### eGanna App से:
1. App खोलें → **"भुगतान विवरण"**
2. Season select करें → Grower Code डालें
3. **Date-wise payment breakdown** मिलेगा

## सोसायटी कोड कैसे पता करें

अगर आपको अपना **Society Code** नहीं पता:

1. **पुरानी पर्ची** पर लिखा होता है
2. **गन्ना विकास अधिकारी** (CDO) से पूछें
3. **मिल office** में जाकर पता करें
4. **eGanna App** → Profile section में दिखता है

## गन्ना सर्वे डेटा कैसे चेक करें

2026-27 का GPS-based सर्वे पूरा हो चुका है:

1. [caneup.in](https://caneup.in) → **Enquiry** → **Survey Data**
2. अपना **Grower Code** डालें
3. **रकबा (area)**, **गन्ने की किस्म**, **अनुमानित उत्पादन** दिखेगा
4. ⚠️ **गलती हो तो तुरंत report करें** — CDO को लिखित शिकायत दें
