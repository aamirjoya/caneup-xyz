## eGanna App में Login कैसे करें? — तीन तरीके

डाउनलोड करने के बाद सबसे ज़रूरी है लॉगिन करना। eGanna App में लॉगिन करने के **तीन तरीके** हैं। मैं एक-एक करके समझाता हूँ।

### तरीका 1: UGC Code से Login

यह सबसे आसान और सबसे तेज़ तरीका है।

**UGC Code** (Unified Ganna Code) एक यूनिक कोड है जो हर गन्ना किसान को दिया जाता है। यह आपकी गन्ना पर्ची पर या मिल के रजिस्ट्रेशन पेपर पर लिखा होता है।

**लॉगिन प्रक्रिया:**

1. eGanna App खोलें
2. **"Login"** बटन पर क्लिक करें
3. **"UGC Code"** वाला ऑप्शन चुनें
4. अपना **UGC Code** टाइप करें (जैसे — UP12345678)
5. **"Submit"** या **"Login"** बटन दबाएँ
6. आपका डैशबोर्ड खुल जाएगा

**UGC Code कहाँ मिलेगा?**
- आपकी गन्ना पर्ची पर
- मिल के रजिस्ट्रेशन स्लिप पर
- ब्लॉक गन्ना कार्यालय में
- CaneUp वेबसाइट पर भी सर्च कर सकते हैं

### तरीका 2: District + Factory + Farmer Code से Login

अगर UGC Code नहीं पता तो यह तरीका इस्तेमाल करें।

**लॉगिन प्रक्रिया:**

1. eGanna App खोलें
2. **"Register Farmer"** या **"किसान पंजीकरण"** पर क्लिक करें
3. **जिला (District)** चुनें — अपने जिले का नाम लिस्ट में से चुनें
4. **शुगर मिल (Factory)** चुनें — जिस मिल में आप गन्ना भेजते हैं
5. **किसान कोड (Farmer Code)** डालें — यह आपकी पर्ची पर मिलेगा
6. **गाँव कोड (Village Code)** डालें — यह भी पर्ची पर होता है
7. **"Submit"** बटन दबाएँ

> **⚠️ एक्सपर्ट वॉर्निंग:** अगर आपका Farmer Code गलत है तो ऐप "No Record Found" दिखाएगा। इसे ठीक करने के लिए अपनी गन्ना पर्ची या मिल के रजिस्ट्रेशन पेपर से कोड मिलाएँ।

### तरीका 3: OTP से Login

अगर आपका मोबाइल नंबर गन्ना विभाग में रजिस्टर्ड है, तो OTP के ज़रिए भी लॉगिन कर सकते हैं।

**लॉगिन प्रक्रिया:**

1. eGanna App खोलें
2. **"OTP Login"** ऑप्शन चुनें
3. अपना **रजिस्टर्ड मोबाइल नंबर** डालें
4. **"Send OTP"** बटन दबाएँ
5. आपके नंबर पर एक OTP आएगा
6. OTP डालें और **"Verify"** करें
7. लॉगिन हो जाएगा

💡 **प्रो-टिप:** अगर OTP नहीं आ रहा तो 2 मिनट इंतज़ार करें। फिर भी न आए तो "Resend OTP" दबाएँ। कभी-कभी नेटवर्क की वजह से देर होती है।

## eGanna App काम नहीं कर रहा — क्या करें? (ट्रबलशूटिंग)

कभी-कभी eGanna App में दिक्कत आती है। यह सामान्य बात है। मैं आपको बताता हूँ कि सबसे आम समस्याएँ क्या हैं और उनका हल क्या है।

### समस्या 1: ऐप खुल नहीं रही

**हल:**
1. इंटरनेट कनेक्शन चेक करें — वाई-फाई या मोबाइल डेटा ऑन है या नहीं
2. ऐप को बंद करें और फिर से खोलें
3. फोन को रीस्टार्ट करें
4. ऐप को अनइंस्टॉल करें और फिर से डाउनलोड करें

### समस्या 2: लॉगिन नहीं हो रहा

**हल:**
1. UGC Code सही है या नहीं, चेक करें
2. Farmer Code और Village Code सही हैं या नहीं, चेक करें
3. जिला और मिल सही चुना है या नहीं, चेक करें
4. ऐप का कैशे साफ़ करें (Settings > Apps > eGANNA > Clear Cache)
5. ऐप को अपडेट करें

### समस्या 3: पर्ची कैलेंडर नहीं दिख रहा

**हल:**
1. लॉगिन सही से हुआ है या नहीं, चेक करें
2. इंटरनेट कनेक्शन चेक करें
3. ऐप को बंद करें और फिर से खोलें
4. अगर अभी सीज़न शुरू नहीं हुआ है तो कैलेंडर नहीं दिखेगा

### समस्या 4: भुगतान स्थिति नहीं दिख रही

**हल:**
1. लॉगिन सही से हुआ है या नहीं, चेक करें

### समस्या 5: ऐप बहुत स्लो है

**हल:**
1. इंटरनेट स्पीड चेक करें
2. फोन की मेमोरी फ्री करें — बेकार ऐप बंद करें
3. ऐप का कैशे साफ़ करें
4. फोन को रीस्टार्ट करें

### समस्या 6: "No Record Found" आ रहा है

**हल:**
1. UGC Code या Farmer Code गलत है — सही कोड डालें

3. आपका डेटा अभी अपलोड नहीं हुआ है — कुछ दिन बाद ट्राई करें

### समस्या 7: ऐप क्रैश हो रही है

**हल:**
1. ऐप को अपडेट करें — Play Store से नया वर्शन डाउनलोड करें
2. फोन का सॉफ्टवेयर अपडेट करें
3. ऐप को अनइंस्टॉल करें और फिर से इंस्टॉल करें
4. अगर फिर भी क्रैश हो रही है तो CaneUp Enquiry वेबसाइट इस्तेमाल करें

> **💡 प्रो-टिप:** अगर कोई भी हल काम नहीं कर रहा तो CaneUp Enquiry वेबसाइट ([enquiry.caneup.in](https://enquiry.caneup.in)) इस्तेमाल करें। वहाँ सारी जानकारी वैसे ही मिलती है।
